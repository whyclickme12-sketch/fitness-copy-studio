# 피트니스 글 변환기 & 금지어 필터

헬스장·PT·필라테스·요가 센터 사장님과 트레이너를 위한 **무료 웹 도구**입니다.
메모 한 줄만 붙여 넣으면 **네이버 블로그 · 인스타그램 · 네이버 스마트플레이스** 문구 3종으로 한 번에 바꿔 주고,
의료법·표시광고법에서 문제가 되는 표현(재활, 치료, 24시간 연중무휴 등 38개)을 실시간으로 잡아 안전한 표현으로 치환합니다.

- 설치 없음 · 회원가입 없음 · API 키 없음 · 단일 HTML 파일(외부 라이브러리 0)
- 입력한 값은 사용자 브라우저(localStorage)에만 저장되고 어디로도 전송되지 않습니다.
- 바로 쓰기: **https://whyclickme12-sketch.github.io/fitness-copy-studio/**

## 쓰는 법

1. 센터 프로필(센터명·지역 키워드·영업시간·연락처)을 한 번 입력합니다.
2. 오늘 찍은 릴스 대본이나 회원에게 설명한 내용을 메모에 붙여 넣습니다.
3. 오른쪽에서 블로그 / 인스타 / 스마트플레이스 문구를 골라 복사합니다.

> 금지어 판정은 일반적인 의료법·표시광고법 해석을 참고한 보조 도구입니다.
> 최종 판단과 책임은 각 센터에 있으며, 중요한 문구는 전문가 검토를 권합니다.
