## 쓰는 법

1. 위쪽 업종 탭에서 내 업종을 고릅니다. (기본값: 헬스장·PT)
2. 매장 프로필(상호·지역 키워드·영업시간·연락처)을 한 번 입력합니다. 업종별로 따로 저장됩니다.
3. 오늘 찍은 릴스 대본이나 손님에게 설명한 내용을 메모에 붙여 넣습니다.
4. 오른쪽에서 블로그 / 인스타 / 스마트플레이스 문구를 골라 복사합니다. 해시태그는 24개를 넘지 않게 만들어집니다.

> 금지어 판정은 일반적인 법령 해석을 참고한 보조 도구입니다.
> 최종 판단과 책임은 각 매장에 있으며, 중요한 문구는 전문가 검토를 권합니다.
